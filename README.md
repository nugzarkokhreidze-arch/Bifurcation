# ბიფურკაცია — ონლაინ თამაში

„ბიფურკაცია“ არის React + Vite-ზე აგებული ონლაინ თამაში სოციალური გამბედაობის, თვითგანვითარებისა და შემოქმედებითი გამოწვევებისთვის.

პროექტი გადაყვანილია AI Studio-ზე დამოკიდებული ვერსიიდან დამოუკიდებელ Vercel + Supabase არქიტექტურაზე.

## ტექნოლოგიები

- React
- Vite
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## ლოკალურად გაშვება

საჭიროა Node.js.

```bash
npm install
npm run dev
